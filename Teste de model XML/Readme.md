# 🤖 Batalha de Modelos & Engenharia de Prompt (XML)

## 📝 Descrição do Projeto

Este projeto foi desenvolvido durante a disciplina de **Engenharia de Prompt e Aplicações em IA** com o objetivo de explorar técnicas de **Prompt Engineering** utilizando estruturação em XML para geração automatizada de páginas HTML com CSS integrado.

A atividade consistiu em criar um **Prompt Estruturado em XML** capaz de instruir diferentes modelos de Inteligência Artificial a desenvolver uma página web single page responsiva e minimalista.

O experimento avaliou diversos modelos de IA generativa, incluindo:

- ChatGPT
- Gemini
- DeepSeek
- Qwen
- Grok
- Maritaca
- Claude

O principal objetivo foi analisar:
- Precisão na interpretação do prompt;
- Qualidade do HTML gerado;
- Criatividade do conteúdo;
- Quantidade de tokens utilizados;
- Presença de erros e bugs.

---

# 🎯 Objetivo da Atividade

Construir um prompt em XML para gerar automaticamente uma página HTML5 contendo:

- Layout responsivo;
- CSS interno;
- Navegação por âncoras;
- Portfólio/Galeria;
- Rodapé com contatos simulados;
- Tema relacionado a “Mestre do Miojo”.

---

# 🧩 Estrutura do Prompt XML

O projeto utilizou uma estrutura organizada em XML para padronizar instruções enviadas às IAs.

Exemplo simplificado:

```xml
<tarefa>
    <objetivo>
        Criar uma página HTML5 única com CSS3 interno.
    </objetivo>

    <tema>Mestre do Miojo</tema>

    <diretrizes_design>
        <layout>Responsivo e minimalista</layout>
        <paleta_cores>Verde Vermelho e Laranja</paleta_cores>
    </diretrizes_design>
</tarefa>
```

# 📈 Resultados Obtidos

Durante os testes foi possível observar diferenças significativas entre os modelos:

- Alguns modelos interpretaram corretamente a estrutura XML;
- Outros ignoraram partes importantes do prompt;
- Houve grande variação no consumo de tokens;
- Claude apresentou a melhor compreensão contextual e precisão técnica.

# 🧠 Aprendizados

Este projeto permitiu aprofundar conhecimentos em:

- Engenharia de Prompt;
- Estruturação semântica em XML;

- Comparação prática entre LLMs;
- Geração automatizada de código HTML/CSS.

Além disso, foi possível compreender como pequenas alterações em prompts impactam diretamente a qualidade da saída gerada pela IA.
